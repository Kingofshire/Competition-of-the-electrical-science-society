# سیستم مسابقه آنلاین

یک اپ کامل برای برگزاری مسابقه: کاربران خودشون ثبت‌نام می‌کنن، به سوالات تستی و کدنویسی
جواب می‌دن، نتیجه‌شون رو بلافاصله می‌بینن، و لیدربورد تا زمان مشخص‌شده **قفل** می‌مونه.

## ✅ امکانات
- ثبت‌نام / ورود با نام کاربری و رمز عبور (self-signup)
- سوالات **تستی (چهارگزینه‌ای)** → تصحیح فوری
- سوالات **کدنویسی** به چند زبان (C, C++, Java, Python, JavaScript, C#, Go, Ruby, PHP, ...) →
  کد کاربر روی سرویس رایگان [paiza.io](https://api.paiza.io) اجرا می‌شه و خروجی‌اش
  با جواب درست مقایسه می‌شه
- هر سوال کدی می‌تونه **چند تست‌کیس** داشته باشه (ورودی/خروجی‌های مختلف) — جواب فقط وقتی
  «درست» حساب میشه که کد روی **همه‌ی** تست‌ها جواب درست بده
- هر کاربر بلافاصله بعد از ارسال، نتیجه سوال (درست/غلط) و خروجی کدش رو می‌بینه
- لیدربورد تا **تاریخ/ساعتی که ادمین تعیین میکنه** برای همه قفله؛ بعدش خودکار باز می‌شه
- پنل ادمین: افزودن/حذف سوال، تعیین زمان پایان، باز کردن دستی زودهنگام لیدربورد،
  دیدن لیدربورد زنده در هر لحظه (حتی وقتی برای بقیه قفله)

## ⚠️ نکته مهم درباره سوالات کدنویسی
اجرای کد به چند زبان مختلف (C/C++/Java/...) نیاز به یک **سرویس اجراکننده کد واقعی** داره.
این پروژه از سرویس رایگان **paiza.io** (با `api_key=guest`) استفاده می‌کنه — نیازی به ثبت‌نام
یا کلید API نیست. این یعنی:
- سروری که این اپ روش اجرا می‌شه باید به اینترنت دسترسی داشته باشه.
- سرویس paiza.io **رایگان ولی بدون تضمین سرویس** و با محدودیت نرخ درخواسته — یعنی ممکنه
  زیر بار زیاد (مثلاً همه‌ی شرکت‌کننده‌ها هم‌زمان کد بفرستن) کند بشه یا موقتاً جواب نده.
  برای یه مسابقه دانشگاهی معمولی معمولاً کافیه.
- توجه: قبلاً این پروژه از سرویس **Piston** استفاده می‌کرد، ولی از ۱۵ فوریه ۲۰۲۶ Piston
  عمومی رو فقط به افراد whitelist‌شده سرویس می‌ده، برای همین به paiza.io سوییچ کردیم.
- **برای مسابقات بزرگ‌تر یا حساس‌تر:** بهترین کار اینه که Piston رو خودتون روی همون سرور
  self-host کنید (رایگان و بدون محدودیت، چون کاملاً مال خودتونه). این نیاز به Docker داره !
## 🚀 اجرا روی سیستم خودتان (لوکال)
```bash
npm install
npm start
```
بعد به آدرس `http://localhost:3000` برید.

رمز پیش‌فرض پنل ادمین `admin123` است — حتماً قبل از مسابقه عوضش کنید:
```bash
ADMIN_PASSWORD="a strong pasword" SESSION_SECRET="a long and random string" npm start
```

**سوالات کدنویسی به‌صورت پیش‌فرض غیرفعال هستند. برای فعال‌کردن آن‌ها متغیر محیطی زیر را نیز تنظیم کنید**:
```bash
ENABLE_CODE_QUESTIONS="true"
```

## ☁️ استقرار روی هاست/سرور (پیشنهادها)
این اپ یک برنامه‌ی Node.js معمولیه، پس روی هر سرویسی که Node رو ساپورت کنه بالا میاد؛ مثلاً:
- **Railway** یا **Render**: ریپو رو وصل کنید، متغیرهای محیطی `ADMIN_PASSWORD` و
  `SESSION_SECRET` رو ست کنید، دکمه‌ی Deploy رو بزنید.
- **یک VPS ساده** (مثل یک سرور اوبونتو): `npm install --production && npm start`
  (پیشنهاد می‌شه با `pm2` اجراش کنید تا اگه کرش کرد خودش بالا بیاد: `npx pm2 start server.js`)

داده‌ها (کاربران، سوالات، پاسخ‌ها) در فایل `data.json` کنار سرور ذخیره می‌شن — نیازی به
دیتابیس جدا نیست. **قبل از هر دیپلوی جدید این فایل رو پاک نکنید**، چون تمام اطلاعات
مسابقه توشه؛ برای بکاپ کافیه همین فایل رو کپی کنید.

## 🖥️ نحوه استفاده
1. اول به `/admin.html` برید و با رمز ادمین وارد شید.
2. سوالات تستی و کدی رو اضافه کنید.
3. زمان پایان مسابقه رو تنظیم کنید و ذخیره کنید.
4. لینک اصلی اپ (`/`) رو برای شرکت‌کننده‌ها بفرستید تا ثبت‌نام و شرکت کنن.
5. بعد از رسیدن به زمان پایان، لیدربورد خودکار برای همه باز می‌شه — یا هر وقت خواستید
   می‌تونید از پنل ادمین با گزینه‌ی «باز کردن دستی» زودتر بازش کنید.

## 📁 ساختار پروژه
```
server.js        سرور اصلی Express (تمام API‌ها)
store.js         ذخیره‌سازی روی فایل data.json + هش کردن رمز عبور
judge.js         اجرای کد کاربر از طریق Piston API
public/          صفحات وب (ورود، سوالات، نتیجه، لیدربورد، پنل ادمین)
```
